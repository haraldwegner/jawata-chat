Agent Control: the proposed view in six states

Mock-ups for the three open decisions. They are the chat's agents bar as the ux report proposes it, not built code. Hover any element for its explanation; fold toggles and the attach buttons work.

1. The bar as it appears: every agent's talk folded

What you see when two agents work and one has finished. Task text under each row, never cut. This is the default state.

2. One agent unfolded

Unfolding shows what the agent and its program said, read only. Folding hides it again.

3. Decision D1: tokens in the row, or only in the cost's mouseover

As built today (signed row P6: tokens and cost)
Proposed (cost only; hover the cost to see the tokens)

4. Decision D2: what attaching a brain asks for

Press “Attach a brain” in each panel.

A (recommended) seat, brain and model, task
B brain only

5. Decision D3: when the bar shows

Proposed hidden until an agent exists
Alternative shown with zero agents

6. Edge states: a failed agent, a compacting agent, an empty transcript

  • Seat name is shown with the command you type, for example architect (/refactor). The agent has to send that command; today it does not.
  • Mouseovers carry the explanations, so the bar itself stays lean.
  • Example data: all agents, tasks, costs and transcripts here are made up for the mock-up.
