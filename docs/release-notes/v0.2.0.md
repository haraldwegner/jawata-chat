# jawata chat and jawata Java v0.2.0

The first release meant for daily use. Two VS Code extensions, versioned and released together, each attached to this release as a `.vsix` file. This release needs jawata-mcp 4.6.0.

## jawata chat

- **The row above the input has five controls and nothing else.** Choosing another brain on a running job replaces the agent doing it; there is no confirmation step, and the principal's row works the same way from the next message.
- **A `/` button** lists your seats and skills, grouped, and filters as you type.
- **A `+` button and paste** attach pictures, sent as pictures to the agents that take them.
- **An indicator** shows that a turn is running, from the moment you send until it ends or you press Stop.
- **Agent Control is a view of its own** in the secondary side bar: it shows the principal and every hire under whoever hired it, at full height with its own scrolling.
- **The side discussion is a view of its own** beside it, with its own session. The Side question button, Ctrl+Alt+S and `/btw <text>` open it and carry your text over.
- **The jawata logo** is in the activity bar and one click shows the chat wherever you placed it.
- The chat follows the editor's colours, and hands them to the studio.

## jawata Java

- **Java Projects** is a view in the Explorer, filled from the engine: projects, classpath and types, and a click opens the class.

## Known limits

- Checked on Linux, in VS Code in an isolated profile. Not run on Windows or macOS.
- A hire longer than about a minute under a Cursor principal shows as failed in the chat, because Cursor gives up on the call. The hire itself goes on.
