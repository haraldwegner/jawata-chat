# jawata chat and jawata Java v0.2.1

This release needs jawata-mcp 4.6.1.

## jawata chat

- **The principal's row and the row above the input name the model that is answering**, and the principal's menu lists the models the agent offers. Choosing one moves the conversation to it.
- **The brain menu stays inside the panel and scrolls** when an agent offers many models.
- **The status bar item reads "jawata chat: …" without the robot icon.** A failure still shows the error mark.

## Known limits

- In the checked VS Code the open menu still reaches to the left of the narrow Agent Control panel, so the start of each entry is cut off; the stylesheet anchors it to the left and a plain browser render shows that, so the cause is not found.
- Checked on Linux, in VS Code in an isolated profile. Not run on Windows or macOS.
