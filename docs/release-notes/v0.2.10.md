# jawata-chat v0.2.10

**A long message of yours is shown folded, and the chat hands the window's folders to the studio again whenever they change.** This release needs jawata-mcp 4.6.10 and jawata-studio 4.6.14.

## What changes

- **A message of yours longer than 6 lines is shown folded:** its first 6 lines, a fade, and `Show all (N lines)`. A click opens it and it stays open; the whole text stays in the page to copy, and the agent's answers are not folded. A long paragraph with no line break folds too, counted by the lines it wraps over.
- **The window's folders follow the window.** Both extensions name their window to the studio and hand its folders over again on every change, so a folder the window opens is reached by jawata's agents at once and one it closes is not, whichever started first. A window left with no folder is forgotten. A window with only the Java extension follows its folders too.
- **A change that arrives while an earlier hand-off is still reading** joins it only when that is the window's latest, and a close resets it, so dropping folders and getting the same ones back is handed over again.

## Known limits

- The folded message was shown in a VS Code window on Linux connected to a replayed agent; the folder hand-off is covered by tests and was not shown in a real window with a live studio.
- Windows and macOS are run by CI, not by hand.
