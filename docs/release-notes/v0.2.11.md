# jawata-chat v0.2.11

**Agent Control is rearranged so the agents and their briefs are told apart, an earlier run is one line that says what it was, and a hire that goes quiet shows as stalled.** This release needs jawata-mcp 4.6.12 (4.6.11 was tagged but never published) and jawata-studio 4.6.15.

## What changes

- **The hires stand in a folded `Hires (N)` line under the principal,** at the third level, so the principal reads first and its team folds beneath it.
- **A brief is labelled `Brief:`** and folds with the same marker as an agent, one glyph in one weight, so an agent and its prompt are no longer mistaken for each other.
- **Each earlier run is one line** with its task, its agents and its cost, and unfolds into its team, replacing the count of finished agents.
- **A stalled hire** (no sign of life for five minutes, as the engine says) counts as working, keeps its Stop and explains its state on its row.
- **The brain of a hire that has ended is no longer a menu** that looks as if it changes the finished run.
- **Agent Control draws the principal's earlier calls only while their fold is open,** so a state change no longer costs as much as the conversation has made calls.

## Known limits

- The new Agent Control arrangement and the stalled state were covered by tests and shown in a replayed agent; they were not shown in a real window with a live studio and a real quiet hire. That is the first dogfood run on this release.
- Windows and macOS are run by CI, not by hand.
