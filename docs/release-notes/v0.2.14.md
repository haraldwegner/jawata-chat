# jawata-chat v0.2.14

**A `btw` button captures a thought with the `/btw` skill, the Seats page offers every brain and warns only where a seat must not change code, and Up and Down in the message field move a line at a time.** It needs jawata-mcp 4.6.14 and jawata-studio 4.6.18. The chat contract is 13.

## What changes

- **A `btw` button** beside *Side question* sends what is in the field as `/btw <thought>`, so a thought is captured for later without leaving the conversation. With nothing in the field it says what to type. A typed `/btw` still opens the side discussion; the button does not go through that rule.
- **The Seats page offers every brain** that can be started here, Antigravity and Cursor-Grok included, and no longer hides a brain whose writes only an instruction holds back. It warns *cannot be restricted from writing* only on a seat that must not change code (the seat row says `changesCode`), and says *not connected* beside a brain that is not logged in. The engine does not prevent the choice.
- **Up and Down in the message field** move through a text that wraps a line at a time before they walk what was sent earlier (the earlier history behaviour is unchanged on the first and last line).

## Known limits

- Covered by the chat's tests. **Not yet shown** in a real window with a live studio: the `btw` button in the chat (the brain must have the `/btw` skill), and Up and Down on wrapped text in a real browser, which has not been tried.
- The warning wording is kept in step by hand with jawata studio's.
- Windows and macOS are run by CI, not by hand.
