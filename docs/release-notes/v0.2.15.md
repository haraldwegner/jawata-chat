# jawata-chat v0.2.15

**A hire the engine refused ends as a row that says why, Up and Down leave a wrap point to the field, and earlier messages are not drawn again for each chunk of a streaming answer.** It needs jawata-mcp 4.6.15 and jawata-studio 4.6.19. The chat contract is 13.

## What changes

- **A refused hire says why.** The chat held a hire the engine refused as the one word *refused*, with no reason, and still offered a brain to choose for a hire that never ran. The contract now knows the state `refused` and the engine's `refusal`; the row shows *Refused: …* under it, with no brain choice and no Stop. Seen in a real window with Antigravity as the principal.
- **Up and Down in a wrapped message** leave a wrap point to the field instead of jumping to the history.
- **Typing while an answer streams into a long conversation** no longer draws the finished answers again for each chunk: 66 ms to the next frame before, 15 ms after, with 2000 messages.

## Known limits

- Covered by the chat's tests and run in a real window under a virtual display against a sandbox engine; **not run** in the studio's own window.
- **A test fix that rides with it:** three tests of the contract package read `docs/phase-a`, which moved to the private plans repository, and failed for that reason. The two byte-for-byte checks of recordings R1 and R2 against those originals are removed (the comparison lives where the originals are), and the local-path check reads the 15 recordings kept here.
- Windows and macOS are run by CI, not by hand.
