# jawata-chat v0.2.16

**After a restart, each editor window reopens the conversation it was showing, with the agent it was held with.** It needs jawata-mcp 4.6.16 and jawata-studio 4.6.20. Install the engine first: with an older engine, reopening stores the conversation's agent as your default. The chat contract is 13.

## What changes

- **Each window comes back to its own conversation.** A window remembers the conversation you typed into or opened from History. A window with nothing remembered, or with no folder open, starts a new conversation on your default agent. New chat forgets it. If a conversation cannot be reopened, a new one starts and one line says why.
- **A message sent while the conversation is still reopening waits for it** and goes to that conversation, on its agent.
- **A Memorize button** replaces the btw button. It sends `/memorize` to the conversation, with the text in the field. Side question and the typed `/btw` are unchanged.
- **A hire's card says calls failed or refused**, and lists each with the engine's message.
- With the new engine, the chat says in the conversation when it could not be saved to History, and why.

## Known limits

- A reopened conversation shows its earlier messages, but the agent does not remember them.
- A reopen the agent never answers has no time limit; a message sent meanwhile waits. Disconnect ends it.
- Covered by the chat's tests; the reopen after a restart was **not run** in a real editor window.
- Windows and macOS are run by CI, not by hand.
