# jawata chat and jawata Java v0.2.2

This release needs jawata-mcp 4.6.2.

## jawata Java

- **Debug a Java program from the editor.** The extension contributes a `jawata` debug type that starts the engine's debug adapter (the launcher with `--dap`). A launch configuration names `mainClass` and `classpath`. A breakpoint stops the program; the stack, the variables, an expression and a step work; each frame names its source file, so a stop in a file with no breakpoint can be opened.
- **The Testing view lists the engine's tests** and runs one, class or method. Progress comes from the engine; a failure shows its message at its line; a run that ran no tests, timed out or did not end as finished is shown as an error, not as passed; cancelling the run cancels it in the engine.
- **Refactorings that need an answer ask for it in one prompt** (change a method's visibility, name the factory method for a constructor). The refactorings that need nothing are code actions at the cursor.
- **A profile page** (the command `jawataJava.profile`) records the running program and lists the hot methods; a click opens the method's source.

## jawata chat

- **A hire card may carry a name**, shown beside the role as `Claudia · pm`; the contract accepts it as optional and refuses one that is not text. An older engine's card without a name is accepted.
- **The contract's sessions include the first real jawata recording**, `R1-jawata`: a turn from jawata's own agent, accepted by the Level-1 check.

## Known limits

- The debugger needs `mainClass` and `classpath` typed in the launch configuration.
- In a real VS Code window (Linux, an isolated profile, only the jawata Java extension) the refactorings, a failing test run, a breakpoint stop with variables, an expression and a step, and the profile request were run through the extension. The Testing view's tree, the refactoring prompt's choice list and the profile page opening were measured in tests over fakes and the protocol, not clicked in a window.
- Recordings of hires, the tree, a stop and a proposal from jawata's agent are not promoted into the contract's sessions: the Level-1 check refuses their hire entries for a missing `model` and `seatCommand`.
- Not run on Windows or macOS.
