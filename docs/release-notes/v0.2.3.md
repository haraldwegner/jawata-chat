# jawata chat and jawata Java v0.2.3

This release needs jawata-mcp 4.6.5 (4.6.4 was never published).

## jawata chat

- **The model is chosen in the chat.** The model shown at the right of the input row is now a picker with the same models Agent Control offers for the principal, and it sends the same request; the change holds from the next message, and both places show it.
- **Up and down in the input bring back what you typed**, newest first, across conversations and restarts, editable before sending. Up recalls only with the cursor on the first line and down only on the last, so a message of several lines can still be edited. The History button (the agent's past sessions) is unchanged.

## jawata Java

- **Red Hat's Java extension, when still installed, is named with what to do.** The warning says it starts a second Java server, names the extensions that need it (an extension pack that holds it included), and offers Uninstall, which removes those first, then Red Hat's, and offers to reload the window. The studio's deploy removes it already; the warning is for an install made after a deploy.

## Known limits

- The model picker, the arrows and the Uninstall button were tested in VS Code's own test runner and against stand-ins, not clicked in a window.
- In Eclipse the arrows' history lasts only while the chat runs; Eclipse keeps it once its chat is next updated.
- With two windows open, the window that sends last keeps its history.
- Not run on Windows or macOS.
