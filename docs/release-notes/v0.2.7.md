# jawata chat and jawata Java v0.2.7

This release needs jawata-mcp 4.6.7.

## jawata chat

- **No "No agent is connected" screen while the agent starts.** While the agent starts and its session opens, the chat shows it is loading. The Connect screen comes back only when there is no connection, or when a start fails.
- **A New session button** beside the input starts a new session with the same agent. The earlier conversation stays in History.
- **Opening another session from History asks nothing.** Sessions are stored, so nothing is lost.
- **Esc closes the "/" list wherever the focus is.** Before, it worked only while the input had the focus.
- **The model list closes on Esc and on a click beside it,** in the chat and in Agent Control. A click inside the list does not close it.
- **Agent Control folds the principal's latest tool calls by default,** with the count on the fold. A click opens them. The earlier ones were folded already.
- **View contract 12** (a new-conversation request from the page). A host that serves the chat page together with its own core needs this version of both. The Eclipse host has not taken it yet.

## Known limits

- Tested in the chat's own test runner and VS Code's test host, not clicked in a window by hand.
- The chat's History shows no session from the last day on the machine this was found on. The cause is not known and this release does not change it.
- Not run on Windows or macOS.
