# jawata chat and jawata Java v0.2.8

This release needs jawata-mcp 4.6.8.

## jawata chat

- **History lists your conversations from every client,** each row with its client (jawata, Claude Code, Cursor), ten at a time with a **Show more** for the next ten. The engine decides what is listed (jawata-mcp 4.6.8); a session the engine started for a brain is left out.
- **Opening a Claude Code or Cursor session shows its recorded messages** and says that a new message there starts with fresh context, because that client does not resume it.
- **Esc closes the topmost open thing:** the model list, then the "/" list, then the History panel, one at a time. A click beside the model list or the "/" list closes it; a click beside History does not, since it has its own Close button. A proposal waiting for your answer and a running turn are not closed by Esc.

## Known limits

- Tested in the chat's own test runner and VS Code's test host, not clicked in a window by hand.
- The side question panel does not close on Esc.
- Not run on Windows or macOS.
