# jawata-chat v0.2.9

**Agent Control shows how each hired agent used jawata, and History reads at a glance.** This release needs jawata-mcp 4.6.9.

## What changes

- **Agent Control, per hired agent:** how its calls split into jawata calls, other calls and shell calls on Java (`12 calls · 9 jawata · 2 other · 1 shell on Java`), how many jawata calls failed or were refused, and how many of its steps ended with no passed gate. Unfolded, the exceptions come first: each shell call on Java with the reason it declared, each failed or refused call with its tool and error code, and the steps with no passed gate. An agent whose calls were counted but not named says "calls not observed", never a zero.
- **Agent Control keeps the latest team shown** after its agents end, with how many calls each made. A hire that reported no tokens shows no tokens figure.
- **A hire the engine refused leaves no card.** The chat takes back the card it drew from the call's input.
- **History reads at a glance:** four columns (client, title, the first eight characters of the session id, date), hovers with the full title, id and exact time, a click on the id copies it for `claude --resume`, and the date reads by distance (`Today 1:39 AM`, `Dec 30, 9:14 PM`).
- **Every code block in an answer has a Copy button** that copies the block's exact text.

## Known limits

- Calls that cannot be tied to a run shown as unassigned, and a client the hook does not watch shown as not observed, are not built.
- Copy and History were shown in a VS Code window on Linux; Eclipse's browser page was not shown with them.
- Windows and macOS are run by CI, not by hand.
